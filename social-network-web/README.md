## О проекте
Данный проект представляет собой полноценную веб-версию социальной сети, разработанную на основе проекта "Модель социальнйо сети". Проект демонстрирует работу с REST API на FastAPI, современным фронтендом на HTML/CSS/JavaScript, хранение данных в JSON-файле с автоматическим сохранением, а также принципы ООП: инкапсуляцию, наследование и полиморфизм.

## Возможности
1. Регистрация нового аккаунта с уникальным логином. 
2. Авторизация по логину и паролю с токеном сессии. 
3. Добавление и удаление друзей. 
4. Создание постов на своей стене. 
5. Просмотр публикаций друзей в ленте новостей. 
6. Отправка и получение личных сообщений. 
7. Смена пароля пользователя. 
8. Автосохранение всех данных в JSON.

## Технологии
*Backend* использует Python 3.8+, FastAPI как веб-фреймворк, Uvicorn как ASGI сервер, Pydantic для валидации данных и JSON для хранения данных.
*Frontend* использует HTML5 для разметки, CSS3 для стилей и адаптивности, JavaScript (ES6+) для клиентской логики и Fetch API для HTTP запросов.

## Структура проекта
В корне проекта находится папка **backend** с файлами `main.py` (FastAPI приложение), `models.py` (классы и модели данных), `requirements.txt` (Python зависимости) и `network_db.json` (база данных, создаётся автоматически).
Также в корне находится папка **frontend** с файлами `index.html` (главная страница), `login.html` (страница входа), `register.html` (страница регистрации), `dashboard.html` (личный кабинет), папкой **css** со стилем `style.css` и папкой js с клиентской логикой `app.js`.

## API Документация
**Базовый URL для всех запросов**: http://localhost:8000/api
*Аутентификация* включает три endpoint: 
1. POST /register для регистрации нового пользователя. 
POST /login для входа в систему. 
POST /logout для выхода из системы.
*Профиль* включает два endpoint:
1. GET /profile для получения данных профиля. 
2. PUT /profile/password для смены пароля.
*Друзья* включают три endpoint: 
1. GET /friends для получения списка друзей. 
2. POST /friends/{username} для добавления друга. 
3. DELETE /friends/{user_id} для удаления друга.
*Публикации* включают три endpoint: 
1. POST /posts для создания публикации. 
2. GET /posts для получения своих публикаций. 
3. GET /feed для получения ленты новостей.
*Сообщения* включают три endpoint: 
1. POST /messages для отправки сообщения. 
2. GET /messages/inbox для получения входящих сообщений. 
3. GET /messages/outbox для получения исходящих сообщений.

## Примеры запросов
1. Регистрация: выполните POST запрос на /api/register с JSON телом содержащим username и password.
2. Вход: выполните POST запрос на /api/login с JSON телом содержащим username и password.
3. Создание публикации: выполните POST запрос на /api/posts с заголовком Authorization содержащим Bearer токен и JSON телом содержащим text.
4. Получение ленты: выполните GET запрос на /api/feed с заголовком Authorization содержащим Bearer токен.

## Важные замечания
1. Безопасность: пароли хранятся в открытом виде
2. CORS настроен для локальной разработки
3. Хранение данных JSON-файл подходит для демонстрации
4. Токены используются упрощённая система аутентификации
